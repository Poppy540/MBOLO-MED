## 5. Leçons apprises

- 2026-09-26 — Vérifier l'existence d'un dossier avant d'y écrire en série (un `cd` échoué a interrompu une création de fichiers ; rien n'a été écrit au mauvais endroit).
- 2026-09-26 — gitleaks utilise le moteur RE2 : pas de lookahead dans les règles ; exclure les valeurs factices par l'allowlist.
- 2026-09-27 — Playwright n'intercepte pas (`page.route`) une redirection qui suit un POST : relever l'URL de retour avec l'événement `request`.
- 2026-09-27 — Un test de refus doit utiliser des identifiants valides, sinon il réussit pour une autre raison (connexion directe : vrai mot de passe, erreur `unauthorized_client` attendue).
- 2026-09-27 — Keycloak : le code OTP se calcule sur les octets bruts du champ caché `totpSecret`, et un code ne peut pas être réutilisé ; importer `authenticationFlows` conserve les flux par défaut.
- 2026-09-27 — HAPI met en cache les recherches 60 s : toujours `Cache-Control: no-cache` pour une décision d'accès (sinon une révocation n'est pas vue). HAPI impose l'intégrité référentielle (un `Consent` vers un `Practitioner` inconnu est refusé).
- 2026-09-27 — Keycloak : déclarer `clientScopes` dans un royaume importé supprime les portées par défaut ; les valeurs `${VAR}` du fichier sont remplacées par l'environnement à l'import (secrets hors dépôt). `tx.fhir.org` peut être indisponible : le validateur réessaie 3 fois.
- 2026-09-27 — Unleash 7 n'a plus la stratégie `userWithId` : cibler une cohorte par une contrainte `userId IN [...]` sur `flexibleRollout`.
- 2026-09-27 — Données e2e persistantes (créneaux) : les retirer en préparation (`entered-in-error`, jamais supprimer), sinon une 2ᵉ exécution échoue (chevauchement).
- 2026-09-27 — Fastify retire en silence les champs inconnus (`removeAdditional`) : pour refuser un texte libre, `ajv.customOptions.removeAdditional = false`.
- 2026-09-27 — WebRTC en local : sans autorisation micro/caméra, Chrome ne propose que des adresses mDNS que LiveKit ignore ; demander les médias **avant** `room.connect`.
- 2026-09-27 — E2E : après un échec, Playwright relance le worker et perd les secrets OTP en mémoire ; les scénarios suivants échouent en cascade (chercher le premier échec).
- 2026-09-27 — Preact : `value` ou `selected` sur un champ de formulaire est réappliqué à chaque rendu et écrase la saisie ; utiliser des champs non contrôlés (`defaultValue`).
- 2026-09-27 — Ne jamais utiliser `pkill -f <motif>` dans une commande qui contient ce motif : elle se tue elle-même.
- 2026-09-27 — Postgres : un quota « compter puis insérer » n'est sûr que sous verrou (`pg_advisory_xact_lock` par cohorte) ; l'usage unique se fait en un seul `UPDATE … WHERE utilise_le IS NULL … RETURNING`. Tester la concurrence sur un vrai Postgres.
- 2026-09-27 — Après une fusion, vérifier que le dernier commit poussé est bien dans `main` avant de réaligner la branche ; ne jamais forcer le push (un commit d'acceptation d'ADR a failli être perdu). Ne jamais ajouter de commit à une PR peut-être déjà fusionnée : vérifier son état juste avant (l'alerte SMS de la PR n°71 est arrivée après la fusion).
- 2026-09-27 — Extension Keycloak : une exception dans `FormAction.success` annule la transaction (le compte n'est pas créé) ; contrôler le code en dernier dans `validate` pour ne pas le « brûler » sur une autre erreur du formulaire. Le point `/registrations` exige aussi PKCE.
- 2026-09-27 — Toujours épingler Keycloak sur la dernière version corrigée : la revue des dépendances a signalé des failles hautes dans 26.0.8 (l'image `26.0` flottante en était aussi touchée).
- 2026-09-27 — Dependabot lit mal les étiquettes Docker à suffixe (`hapiproject/hapi:v8.12.0-1`) : il a proposé v8.0.0, une version ancienne. Toujours vérifier la dernière étiquette réelle avant de fusionner une PR d'image.
- 2026-09-27 — Unleash 8 : code sous AGPLv3 (images Docker officielles sous Apache 2.0) ; le paquet npm est en modules ES (`import * as unleash`).
- 2026-09-27 — Keycloak : déclarer `requiredActions` dans un royaume importé supprime les actions non déclarées (dont `CONFIGURE_TOTP`) : toujours lister les actions par défaut.
- 2026-09-27 — CodeQL (`js/missing-rate-limiting`) ne reconnaît que les limiteurs de bibliothèques connues : `@fastify/rate-limit`, enregistré avec `await` avant les routes (la fabrique du serveur devient donc asynchrone). Appliqué à tous les services depuis la PR AJ.
- 2026-09-27 — `@types/fhir` s'importe via `'fhir/r4.js'` en `NodeNext` ; les fausses clés de test se construisent à l'exécution pour ne pas déclencher gitleaks.
- 2026-09-27 — SeaweedFS : chaque compartiment crée une collection de 7 volumes ; avec la limite par défaut, le 2ᵉ compartiment échoue (« Not enough data nodes ») : lancer avec `-volume.max=100 -master.volumeSizeLimitMB=64 -master.volumePreallocate=false`.
- 2026-09-27 — Keycloak limite la description d'un rôle et le nom d'un client à 255 caractères : au-delà, l'import du royaume échoue au démarrage (« Attendre Keycloak » en échec par délai, code 124 ; un test vérifie les deux depuis la PR n°174).
- 2026-09-28 — Un test d'intégration qui crée une ressource externe (compartiment S3) doit la supprimer à la fin : sinon le stockage local s'épuise après une quinzaine d'exécutions, alors que la CI (conteneur neuf) ne le voit jamais.
- 2026-09-28 — Recherche FHIR : toujours suivre les pages (`ClientFhir.rechercher`) ; en e2e local, les fiches des exécutions précédentes dépassent vite une page, et un compte « sur la 1ʳᵉ page » devient faux.
- 2026-09-28 — Toute écriture d'un `Appointment` que le passage périodique peut aussi faire (confirmer, annuler) doit gérer le conflit de version : relire, puis rendre le résultat ou réessayer une fois. En e2e local, un premier échec en entraîne des dizaines d'autres (secrets OTP perdus) : toujours chercher le premier.
- 2026-09-28 — E2E : ne pas annuler un rendez-vous payé avant sa confirmation ; le passage périodique écrit le même `Appointment` et le dossier refuse l'une des deux écritures (conflit de version). Toujours vérifier le résultat d'une étape d'action dont dépend la suite.
- 2026-09-28 — E2E : un créneau « maintenant + N jours » peut chevaucher un créneau publié à heure fixe le même jour, selon l'heure d'exécution (échec entre 08 h 40 et 09 h UTC). Donner à chaque scénario ses propres jours ; reproduire à la même heure avant de conclure.
- 2026-09-29 — En local, HAPI remis à zéro (redémarrage du conteneur) réutilise les numéros de rendez-vous alors que la base des paiements les garde : `paiement` refuse une référence déjà liée à un autre patient (→ 503 à la réservation). Après une remise à zéro de HAPI, vider aussi les tables locales du schéma `paiement`.
- 2026-09-29 — Keycloak : un fichier de royaume importé accepte `${VAR:défaut}` (vérifié sur 26.7.4) ; utile pour un réglage qui change en production sans casser le local.
- 2026-09-29 — Un compteur gardé en base survit d'une exécution e2e à l'autre (contrairement à la mémoire) : relever la limite dans la configuration e2e et tester la limite à part.
- 2026-09-29 — E2E locaux : les services tournent depuis `dist/` ; reconstruire le service modifié (`pnpm build`) avant de lancer la suite, sinon elle teste l'ancien code (la CI, elle, reconstruit tout).
- 2026-09-29 — Keycloak : dans une action requise, `setFormData` ne remplit pas `formData` du gabarit ; passer les valeurs par `setAttribute`. `setErrors` avec une liste vide fait échouer le gabarit (`message.summary` absent).
- 2026-09-29 — Keycloak : un jeton rafraîchi garde l'`acr` de la session (niveau 2 encore là après 16 min, au-delà de `loa-max-age`) ; un client qui n'utilise pas les jetons de rafraîchissement doit avoir `use.refresh.tokens: false`.
- 2026-09-29 — Keycloak : `failureChallenge` dans un authentificateur compte un échec de connexion ; après quelques codes SMS faux, la protection contre la force brute bloque le mot de passe (« identifiant ou mot de passe invalide »). Pour une erreur de saisie déjà limitée par l'extension, utiliser `challenge`. Keycloak rend l'apostrophe droite (') dans ses messages.
- 2026-09-30 — SeaweedFS lancé sans `-volume.port` prend le port 8080 de HAPI (qui répond alors 400) : volume sur 8090 en local. Après un redémarrage de l'environnement, vider aussi les paiements locaux (HAPI repart de zéro).
- 2026-09-30 — Les e2e refusent tout SMS contenant « dr », « pat- », « prac- » ou « motif » (sans casse) pour ne jamais citer de médecin ni de dossier : un mot comme « viendront » échoue ; relire chaque nouveau gabarit avec ce filtre. Keycloak : un code TOTP ajouté par l'action standard `CONFIGURE_TOTP` est possible avec le seul mot de passe ; ne jamais s'y fier pour un niveau d'authentification.
- 2026-10-01 — axe-core 4.13 : `target-size` (WCAG 2.2) est désactivée par défaut et `withTags` ne l'active pas ; `options()` remplace le filtre de `withTags` (passer `runOnly` avec). Avant de pousser : aussi `pre-commit run --all-files` (`pnpm verifier` ne contrôle pas les espaces en fin de ligne).
- 2026-10-01 — Le gabarit `keycloak.v2` de Keycloak 26.7.4 laisse sans libellé le champ `kc-attempted-username` (le libellé vise `username`) : copie corrigée dans le thème `mbolo`, à reprendre à chaque mise à jour de Keycloak. Un contrôle axe qui ne trouve rien doit être vérifié sur une page fautive avant d'y croire.
- 2026-10-01 — axe-core ne contrôle pas la redistribution (WCAG 1.4.10) : la vérifier à part (320 px, `scrollWidth`). Un élément caché (`visibility: hidden`) positionné hors de l'écran élargit quand même la page. Thème Keycloak enfant : `styles=css/styles.css css/mbolo.css` sert la feuille du parent et la sienne.
- 2026-10-03 — Dépôt privé sur le plan gratuit (redevenu public le 2026-10-27) : CodeQL, la revue des dépendances et la protection des branches ne sont plus disponibles ; un contrôle qui échoue sans lien avec la PR peut venir d'un réglage du dépôt (lire le journal avant de chercher dans le code). `semgrep.dev` est bloqué dans l'environnement Claude Code : règles prises sur GitHub (`semgrep/semgrep-rules`).
- 2026-10-27 — Jobs en échec en 3 secondes, annotation « The job was not started because recent account payments have failed » : facturation GitHub, pas le code ; relancer ne sert à rien tant que le compte n'est pas réglé (lire les annotations de la check-run avant tout).
- 2026-10-27 — La CI n'audite que les dépendances de production (`--prod --audit-level high`) : des failles hautes d'outils de développement (vite, source-map-js) restent invisibles ; lancer aussi `pnpm audit` complet. Une dépendance transitive ne monte qu'avec `pnpm update -r --depth Infinity <paquet>`.
- 2026-09-30 — E2E : après `autoriser` (retour Keycloak vers le faux port 5173, jamais servi), la page finit en erreur Chrome un peu plus tard ; un `page.goto` suivant sur la même page peut être interrompu (« interrupted by another navigation to chrome-error »). Ouvrir une nouvelle page (`context.newPage()`) pour la navigation suivante.
