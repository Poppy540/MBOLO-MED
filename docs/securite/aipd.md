# Analyse d'impact relative à la protection des données (AIPD) — Mbolo Santé

> Squelette. Obligatoire avant la vague 1 (traitement à grande échelle de données de santé, usage d'IA). Méthode inspirée du guide AIPD de la CNIL (https://www.cnil.fr/fr/RGPD-analyse-impact-protection-des-donnees-aipd).

1. **Description du traitement** : finalités, données, flux, acteurs, agents IA.
2. **Nécessité et proportionnalité** : bases légales, minimisation, durées, droits des personnes, consentement révocable.
3. **Risques pour les personnes** : accès illégitime, modification non désirée, disparition des données ; risques spécifiques à l'IA (erreur d'orientation, biais, injection de prompt).
4. **Mesures** : techniques, organisationnelles, humaines (validation médicale).
5. **Avis** : DPO, comité médical, porteur de projet. **Décision.**
