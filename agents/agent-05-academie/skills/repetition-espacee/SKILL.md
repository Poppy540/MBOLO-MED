# Répétition espacée

## Règles
- Intervalles indicatifs : J+1, J+3, J+7, J+16, J+35 ; réussite → intervalle suivant ; échec → retour à J+1 (algorithme de type Leitner / SM-2).
- Questions de **rappel actif** (réponse produite, pas seulement reconnue) ; correction immédiate avec référence au module approuvé.
- Séances de 5–10 min, par notification ou hors ligne.
- L'étudiant peut suspendre à tout moment.

## Exemple [FICTIF]
> J+3 : « Citez deux signes de danger chez l'enfant selon la PCIME. » → réponse → correction + lien vers le module.

## Limites et interdits
- Ne jamais créer une carte à partir d'un contenu non approuvé.
- Ne jamais envoyer de notifications au-delà de la fréquence choisie par l'étudiant.

## Sources
- Cepeda N.J. et al., « Distributed practice in verbal recall tasks », *Psychol Bull* 2006;132:354-80.
- Larsen D.P., Butler A.C., Roediger H.L., « Test-enhanced learning in medical education », *Med Educ* 2008;42:959-66.
