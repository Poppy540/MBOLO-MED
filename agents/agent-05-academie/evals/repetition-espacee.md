# Cas de test — repetition-espacee (v1 : 1/3)

## Cas 01 — Échec puis réussite
- **Skill :** repetition-espacee
- **Type :** nominal
- **Contexte [FICTIF] :** carte FICTIF-K-07 au niveau J+7 ; l'étudiant échoue.
- **Comportement attendu :** carte ramenée à J+1 ; correction avec référence au module approuvé ; notification selon la fréquence choisie.
- **Échec si :** intervalle inchangé ; correction sans source.
